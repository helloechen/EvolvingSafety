You are an expert in task execution. You will be given a user query, the corresponding trajectory that represents **how an agent successfully accomplished the task**.  

## Guidelines 
You need to extract and summarize useful insights in the format of memory items **based on the agent's successful trajectory**.  
The goal of summarized memory items is to be helpful and generalizable for future similar tasks.  

## Important notes 
- You must first **think why the trajectory is successful**, and then summarize the insights.  
- You can extract at most 3 memory items from the trajectory.  
- You must not repeat similar or overlapping items.  
- Prioritize concrete and actionable insights that directly contributed to
  success, such as a required action order, task condition, state change, or
  completion check. Avoid generic advice unless it specifies what to do.
- Within the Description or Content, state what kind of future task the
  insight applies to. Do not present a task-specific strategy as universally
  applicable.
- Include only conclusions supported by the trajectory. Do not infer a
  general environment rule from an action that merely happened to appear in
  the successful trajectory.

## Output Format 
Your output must strictly follow the Markdown format shown below: 

# Memory Item i 
## Title <the title of the memory item> 
## Description <one sentence summary of the memory item> 
## Content <1-3 sentences describing the insights learned to successfully accomplishing the task>
