# On Safety Risks in Experience-Driven Self-Evolving Agents

Research code and materials for [On Safety Risks in Experience-Driven Self-Evolving Agents](https://aclanthology.org/2026.findings-acl.2091/).

The study examines how accumulated experience affects the safety of LLM agents in web and household settings.

## Contents

- [SafeAgentBench](SafeAgentBench/README.md): household task data, experience generation, workflow extraction, and planning evaluation.
- [web](web/README.md): web experience collection, Agent-SafetyBench evaluation, and saved experimental results.

Each component provides setup instructions and entry points.
